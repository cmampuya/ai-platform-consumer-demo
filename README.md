# ai-platform-consumer-demo

Demonstration consumer of [ai-engineering-platform](https://github.com/cmampuya/ai-engineering-platform).
It exists to verify, on real GitHub infrastructure, that Dependabot's `gitsubmodule` ecosystem
proposes a newer platform release tag, and that the consumer CI template works.

Started pinned to `v0.1.0`. See the platform's `docs/consumers.md`.
